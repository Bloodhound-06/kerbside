# Kerbside

Race recording, a broadcast-style stream overlay and replay videos for **iRacing**, as a **SimHub** plugin plus a Windows program.

## Install
1. Install [SimHub](https://www.simhubdash.com/) if you don't have it.
2. Download **KerbsideSetup.exe** from the [latest release](../../releases/latest).
3. Close SimHub, run KerbsideSetup.exe and click **INSTALL**.
   - Windows may show **"Windows protected your PC"**: Kerbside isn't code-signed (it's free). Click **More info → Run anyway**.
   - Windows asks for administrator rights once, to put the plugin into SimHub's folder.
4. Start SimHub and click **Yes** when it asks to enable **Kerbside**.
5. Open **Kerbside** from the Start menu.

Kerbside keeps itself up to date: the SimHub plugin every time SimHub starts, the program every time you open it.

## Uninstall
Windows Settings → Apps → Installed apps → **Kerbside** → Uninstall. You choose whether to keep your recordings and settings.
